# Como contribuir com o Entenda

Obrigado pelo interesse. O projeto está em fase inicial e ainda não possui fluxo de desenvolvimento completo.

## Antes de contribuir

1. Leia o [README](README.md), as [diretrizes de agentes](AGENTS.md) e a [política editorial](docs/EDITORIAL_POLICY.md).
2. Para alterações relevantes, proponha o escopo em uma issue antes de investir em implementação extensa.
3. Faça mudanças pequenas, com descrição clara do problema e da solução.
4. Inclua testes quando houver código executável e descreva as verificações realizadas.
5. Não envie dados pessoais, credenciais, tokens ou documentos restritos.
6. Preserve neutralidade política, rastreabilidade das fontes e revisão humana para conteúdo editorial.

## Pull requests

Descreva motivação, arquivos afetados, riscos, testes executados e limitações. Não presuma aprovação automática de alterações editoriais, jurídicas, de segurança ou infraestrutura.

## Licença

A licença de código ainda será formalizada no arquivo `LICENSE`. Até lá, o repositório é público, mas não deve ser tratado como software com licença open-source concedida.
