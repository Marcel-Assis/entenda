# Entenda

Plataforma brasileira de informação e transparência pública, com contexto, dados e evidências.

> Projeto em fase inicial de desenvolvimento.

O Entenda busca tornar informações sobre instituições, processos legislativos e atividades públicas mais acessíveis, com neutralidade editorial, rastreabilidade das fontes e correções transparentes.

A documentação técnica e as orientações para contribuição serão adicionadas nas próximas etapas.
