# Segurança

Não publique vulnerabilidades exploráveis em issues públicas.

Até a definição de um canal privado de reporte, use os recursos privados de segurança do GitHub, caso estejam habilitados, ou contate os mantenedores por um canal privado apropriado.

Nunca inclua credenciais, tokens, dados pessoais ou informações sensíveis em relatórios públicos. O projeto está em fase inicial; não há SLA de resposta estabelecido.
